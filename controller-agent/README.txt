ScreenFleet Controller Agent (NovaStar VX)
==========================================
sf-controller-agent.zip - runs on the truck PC and relays ScreenFleet Controls
commands to the NovaStar VX600 / VX1000 / VX400 over the LAN (port 5200) or USB.

Setup (download it from Controls > LED controller > Setup in ScreenFleet):
  1. Unzip to C:\ScreenFleet\controller-agent
  2. In ScreenFleet, click "Generate agent key" on the truck PC (saves to Downloads)
  3. Close NovaLCT, double-click "Install auto-start.bat"

No keys or customer data are in this package; each truck's key comes from ScreenFleet.
