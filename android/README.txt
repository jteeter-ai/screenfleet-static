ScreenFleet Player for Android (TV boxes and sticks).

  dev.apk                            Latest TEST build (always the newest dev build).
  ScreenFleet-Player-<ver>-dev.apk   The same build, by version.

Test builds install as com.screenfleet.player.dev and are signed with the public dev key.
They are NOT customer builds: customer builds (com.screenfleet.player) will be signed with
the ScreenFleet release key and published here separately.

Source and build history: github.com/Legion-LED/screenfleet-player-android (private).
Each build there is published as a "build-<n>" prerelease; copy its APK here as dev.apk.
